# Changelog

## v0.3.0 (2026-01-16)

### Added

- **Admin Settings Page**: Added a plugin configuration page

- Configurable default Web Service short name

- Configurable whitelist of allowed Web Services

- Configurable Site Identity and Passport Secret (for advanced security authentication)

### Changed

- **Service Parameters**: Default services can now be configured via the admin panel instead of being hard-coded.

- **Service Authentication**: Added Web Service whitelist authentication for improved security.

### Security

- Administrators can now restrict which Web Services can be used for SSO.

- Supports Passport authentication (optional).

## v0.2.0 (2026-01-15)

### Added

- Initial release

- Supports Web and mobile app SSO

- Implements basic token generation functionality

- Added event logging
